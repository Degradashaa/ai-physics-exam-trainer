# ---
Проект представляет собой ИИ-тренажёр для подготовки к устному экзамену по физике. Он решает проблему дефицита времени учителя: приложение выдает билет, задает уточняющие вопросы и проверяет развернутый ответ. Оценка ставится строго по рубрике и эталону, а не мнением нейросети, что снижает галлюцинации. Стек: Python, Streamlit, Groq API.
