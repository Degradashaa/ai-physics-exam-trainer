# Описание проекта

**Тема:** ИИ-тренажёр для подготовки к устному экзамену по физике
с проверкой ответа по рубрике.

**Проблема:** устный экзамен требует развёрнутого ответа, а обратная
связь доступна только от преподавателя. Массовая подготовка упирается
в дефицит времени учителя.

**Решение:** веб-приложение, которое:
1. выдаёт билет из базы;
2. задаёт уточняющие вопросы (LLM, Groq);
3. проверяет ответ по заранее заданным критериям;
4. возвращает баллы, список пропусков и ошибок, оценку.

**Ключевая идея:** оценка ставится **по рубрике и эталону**, а не «мнением»
модели. Это снижает галлюцинации и делает проверку объяснимой.

**Стек:** Python, Streamlit, Groq API (openai/gpt-oss-120b),
JSON-база вопросов.
